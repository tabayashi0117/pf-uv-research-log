## 番号の引き方

- `E05-Pn` は `PROVED_E05.md` の見出し `## E05-Pn(…)` で引く。本文の「v-b」は格付け verifier-backed(独立な監査を通った)、「self-audited」は書いた体の敵対的セルフレビューだけを通ったもの、「candidate」はその前。
- `Fn`(接頭辞なし)は `FAILED_E05.md` の見出し `## Fn(…)`。`E05-Fn` は別の名前空間(再検証しない公理として使った事実の番号)で、台帳の中では `E05-F26` のように常に接頭辞つきで書かれている。同じ数字が別の中身を指すので注意。全件の 1 行索引は `catalog/failures_index.md`。
- `Sn`・`S-E05-…` は `成算_E05.md` の見出しか、行頭の `- **Sn…` の項。
- 稿番号(「稿 `562_`」「定理 560-T」「補題 539-N」など)は研究ノートの稿のファイルの番号で、稿そのものはこのリポジトリに無い。台帳の各件に、その稿のどの節に証明があるかが書いてある。
- 監査の番号(「監査 561」「S2 565」「A-566-1」)も研究ノートの監査記録の番号。`A-…` は監査人が自分で書いた補題で、別の体の独立確認を受けた記録が台帳の見出しにある。

## 整理の規則(機械的に当てたもの)

機械で整理した。

1. この記録の範囲(論文 I・II に関わるところ)の外の件は除いた。除いた番号は欠番になる。
2. パス:絶対パスは「(研究ノート)」に、研究ノートの中のパスは「(研究ノート: `ファイル名`)」に置き換えた。運用の規則のファイルへの参照は、このリポジトリの写し(`rules/…`)の路に付け替えた。
3. 計算機名:「計算機 1」〜「計算機 6」に置き換えた(3 は小型の GPU ボード、4 は研究者の手元のノート PC、5・6 は別のノート PC;機械の構成は [`book/ja/03_数値計算.md`](../../book/ja/03_数値計算.md))。
4. 体の型とモデルの名:本の呼び方に合わせ、型の名を「監査の型」「書き下しの型」「機械作業の型」「難所の型」に、モデルの名を「重いモデル」「軽いモデル」「最上位のモデル」に置き換えた。識別子の中の接頭辞も英字の別名に変えた。
5. ID:セッション・サブエージェントの ID は「(ID)」に置き換えた(該当は 0 件)。

上の置き換え以外は、台帳の本文をそのまま写している。台帳は研究の途中に追記型で書かれたもので、後で覆った判定には本文の冒頭に訂正・格下げの注記が重ねてある(本文は書き換えない規則だった —— [`book/ja/04_AIとの協業.md`](../../book/ja/04_AIとの協業.md))。読むときは各件の見出しの格付けと冒頭の注記を先に見てほしい。
