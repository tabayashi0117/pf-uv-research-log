# 失敗の全件の索引(E05 の FAILED 台帳)

E05(Pauli–Fierz 模型の紫外の切断を外す研究)の失敗の台帳 FAILED の全ての見出しを、スクリプトで機械的に抜き出した 1 件 1 行の索引です。本文の章は [`book/ja/02_証明と失敗.md`](../book/ja/02_証明と失敗.md)。

## 読み方

- **番号**:台帳の F 番号(2026-09-02 の F1 から 2026-10-22 の F451 まで)。番号の重複が 2 件(F115・F204)あり、両方を載せています。番号の欠け(3 件)は、この記録の範囲の外の件として除いたものです。「(注記)」は番号のない注記の見出し。
- **日付**:見出しか本文の冒頭にある最初の日付。末尾に `?` があるものは日付の書かれていない件で、直前の件の日付を仮に入れています。
- **分類**:見出しと本文の冒頭の語で機械的に振ったもの(上から最初に当たった 1 つ)。境界の件は人が読むと別の分類になることがあります。
  - 有効質量の冪:質量比 $h(\lambda)$ の $\lambda$ についての冪(初期の主問題)。
  - 自己エネルギー:基底エネルギー $E_0$ とその冪。
  - (E1)・殻:紫外の殻の光子・雲のブースト・縁の項など、(E1) と呼んだ入力の系列。
  - 全列:「全ての大きな $\lambda$ で $h\to\infty$」(行 E1-H)を、対数密度 1 の集合から全ての点へ広げる系列。
  - J-G の鎖:全列の計画 Ⅰ の芯(平均場の汎関数で Born–Oppenheimer の下界を払う鎖)。
  - 難問 #1・#2・#3:研究の後半に名付けた 3 つの難問(#1 くりこまれた極限の構成の門 $\iota\gt0$、#2 自己エネルギーの冪、#3 上側の一様版)。
  - 構成の方式:Gross 変換・内部境界条件・RG・Feshbach などで切断なしの模型を直接作る方式。
  - 数値:モンテカルロ・MPS・区間演算などの計算の方式と装置の失敗。運用:記録や手順の事故。その他:上のどれにも機械的に当たらなかったもの。
- **閉じたもの**:台帳の規則で書くことになった「方式 / 標的 / 命題の真偽」のどれを閉じたか(本文の「閉じたもの」「閉じたのは」の直後の語から機械的に判定)。「読み」は解釈を閉じた件、「否定の筋」は標的が偽になる機構の候補を閉じた件。「—」は、その書式が無い時期(主に 9 月)の件か、本文に明記の無い件。
- **後で覆ったか**:本文の冒頭に格下げ・一部撤回の注記がある件と、後の件から訂正の参照を受けた件。機械抜きなので漏れがあり得ます。2026-10-27 に台帳を作り直したとき、新しい F 番号は無く、既存の件への注記だけが増えていたので、索引は作り直さず、決着が変わった F26 の 1 行だけを手で直しました。
